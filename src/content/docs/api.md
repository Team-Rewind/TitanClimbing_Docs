---
title: API Reference
description: Reference for Titan Climbing components and generated surface assets.
---

Use the API tabs to configure the three primary Titan Climbing asset types:

- [Titan Climbing Component](./api/titan-climbing-component/) configures the player-side climbing system.
- [Titan Climbable Component](./api/titan-climbable-component/) configures animated skeletal targets.
- [Titan Surface](./api/titan-surface/) configures and generates the surface data used by climbable Titans.
