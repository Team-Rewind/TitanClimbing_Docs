## Build traversal that moves with the world

Titan Climbing lets a character find an eligible surface, anchor to it, and traverse it while the surface animates or moves. Use it with a static climbable mesh or a skeletal **Titan** with generated, skinnable surface data.

## The workflow at a glance

1. **Prepare the player** — attach the Titan Climbing component and provide the climb input.
2. **Prepare the target** — add a Titan Climbable component to an animated skeletal actor, or configure a static climbable mesh.
3. **Generate surface data** — create a Titan Surface from the target mesh and assign it back to the target.
4. **Tune and ship** — use the component settings and Blueprint API to refine traversal, transitions, debugging, and network presentation.

## What is included

<CardGrid>
	<Card title="Character-side traversal" icon="person">Surface anchoring, limb probes, climb transitions, cling, jumps, and walking on moving Titans.</Card>
	<Card title="Animated surface queries" icon="search">Skinned surface data with raycasts and sphere/capsule sweeps, backed by an optional BVH.</Card>
	<Card title="Editor authoring" icon="setting">Titan Surface generation with reduction, welding, normal flattening, and runtime raycast data.</Card>
</CardGrid>
