## Installation

1. Add the Titan Climbing UE plugin to your Unreal project.
2. Enable the plugin in the Unreal Engine plugin manager.
3. Restart the editor if Unreal prompts you to do so.

## First setup

1. Open the project settings or plugin settings for Titan Climbing UE.
2. Configure the plugin-specific paths, defaults, or project options.
3. Create or load the first climbing setup for your project.

## Next step

After setup, review the [API](./api) page for the main plugin surfaces and the [FAQ](./faq) page for common issues.
